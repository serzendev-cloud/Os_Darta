3. **Branch Spawning & Membership Models**: Branch identity binding and deterministic indexing over $\{0, \dots, k-1\}$;
4. **Barrier Satisfaction Conditions**: Criteria for structural fork satisfaction;
5. **Partial Satisfaction Representation**: Bounded modeling of interim branch preparation;

8. **Invalidation Interaction Boundary**: Contract for handling incoming `INVALIDATED` signals without resolving invalidation policy;
9. **Barrier Release Conditions**: Deterministic release criteria triggering downstream branch eligibility;
