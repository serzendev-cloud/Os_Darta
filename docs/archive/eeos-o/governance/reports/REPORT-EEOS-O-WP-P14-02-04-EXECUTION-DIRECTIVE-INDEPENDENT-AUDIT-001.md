## 6. Audit Observations

* **OBS-01 (Boundary Vigilance on Local Barrier Failure vs. Downstream Propagation)**:
  §4.7 (Q7) requires defining deterministic triggers leading to `FAILED`, barrier failure containment, and sibling branch isolation. The architectural author must ensure that the specification addresses only the *barrier's internal state machine reaction* to failure signals, and does not specify cross-branch cascading propagation algorithms, deadlock detection heuristics, retry daemons, or container cancellation engines, all of which are strictly quarantined under `WP-P14-02-05`.
* **OBS-02 (Telemetry Payload Non-Cryptographic Boundary)**:
  §4.7 (Q7) references "failure telemetry and evidence emission schemas." The architectural author must ensure that these schemas define solely declarative JSON event payloads for macro-orchestration diagnostic visibility, and strictly avoid introducing cryptographic hash bindings, Merkle node hashes, or persistent ledger structures, which remain strictly quarantined under `OAQ-SYNC-01` and Phase 1.6 (`DO_Laporan`).

Both observations represent non-blocking architectural boundary reminders and do not prevent sovereign authorization.
